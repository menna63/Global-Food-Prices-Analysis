# Global Food Prices Analysis

## Project Overview

This project focuses on analyzing global food prices using the **WFP Food Prices 2026** dataset. The project involved data cleaning and transformation, data modeling using a **Star Schema**, and developing an interactive **Power BI dashboard** to present meaningful insights.

## My Contribution

I was responsible for the **Power BI part of the project**, including:

* **Data Cleaning & Transformation:** Cleaned and transformed the raw data using **Power Query**.
* **Data Modeling:** Designed a **Star Schema** and established relationships between the tables.
* **Dashboard Development:** Created an interactive **Power BI dashboard** using KPIs, charts, and visualizations to highlight key insights.

## Dataset

**WFP Food Prices 2026**

The dataset contains food price information from different countries, markets, commodities, and time periods.
